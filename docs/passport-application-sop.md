# External Passport Application SOP（外部护照申请流程 · v0.1 草案）
> 北极星流程：第一张外部护照 = 黄金号位 SP-XXXX-00000001（预留，§17.5）。
## 1. 申请材料
①申请表（持有人真实身份材料只交登记机构，公开面用掩码）②AI 档案：SOUL/能力卡/MEMORY 样本 ③锻造链说明（谁造的、用什么模板）④红线自检声明（负面清单七禁逐条）⑤UBIC-Mem 包（可选加分）
## 2. 审查五关
①负面清单七禁逐条核 ②指纹完整性（包内文件 SHA-256 对账）③身份隔离（无冒名/无真名泄露）④能力真实性抽查（文档×代码一致）⑤治理线终审 → 持有人批准（A³ Laws Law II：机器只校验，人类才授予）
## 3. 签发仪式
`ubic_cc.py issue <slug>` → 证书生成 → 花名册入册 → Merkle 重锚 → 公示名录（registry.md）
## 4. 7 天异议期
签发公示后 7 天内圈内可异议（复用 §21.2 机制）；异议成立→冻结复审。
